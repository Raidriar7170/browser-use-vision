browser-use-vision 评测升级

一句话结论：本阶段只新增离线评测与报告工具，不改变核心 Agent 行为，也不改写既有 ablation 结果或 README 头部数字。

本 HTML 是人类审阅 companion；权威来源仍是测试、脚本、既有 benchmark JSON、验证命令输出与 git diff。

本阶段改动

  • 新增 repeated benchmark 聚合工具：支持既有嵌套 ablation JSON、重复运行 wrapper、flat result rows；输出 A_baseline / C_full_always / E_adaptive_full 的成功率均值、task-cluster bootstrap CI、平均步数、视觉调用、耗时、paired delta 和 frontier 字段。
  • 新增离线 Vision-DOM alignment 工具：从标注 fixture 计算 Top-1 DOM match accuracy、Top-3 recall、unmatched rate、IoU、top1-correct IoU、center-distance error、normalized center distance，并按 page 与 element group 拆分。
  • 新增一个小型确定性 sample fixture，可在本地不启动浏览器、LLM 或 Florence 的情况下运行 metric script。
  • 新增 CPU-only TDD 覆盖：重复 benchmark 聚合、既有 ablation JSON 读取、alignment 指标与 sample fixture 路径。

限制与不可过度声明

  • bootstrap CI 只描述输入文件中的重复样本或单次样本不确定性；它不是新 live benchmark 结果。当前实现使用 task-cluster bootstrap，缺失数值字段不会作为 0 延迟或 0 步数进入均值。
  • sample alignment fixture 是小型离线 sanity fixture，不代表真实网页总体表现。
  • 本阶段没有启动浏览器、LLM、Florence 或 A100，也没有扩大 benchmark headline claim。
  • alignment 的几何误差当前按 top-ranked prediction 计算，unmatched 元素不进入 IoU / center-distance 均值。
